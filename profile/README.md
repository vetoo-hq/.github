# Vetoo

Vetoo reviews pull requests on GitHub and GitLab. A panel of agents running on several models reads each change, posts inline findings with suggested fixes, and answers follow-up questions in the thread. The code is deleted when the review ends.

- Install the GitHub App: https://github.com/apps/vetoo-review
- Docs: https://docs.vetoo.dev
- Pricing: https://vetoo.dev/#pricing
- Sub-processors and retention: https://vetoo.dev/subprocessors

Our product repositories are private. Questions and bug reports go to support@support.vetoo.dev.
